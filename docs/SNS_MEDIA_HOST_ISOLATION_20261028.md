# Immutable media host entrypoint isolation

The existing bounded media-preparation shell now disables inherited shell tracing before handling configuration, uses a private umask and loads only the fixed shared runtime environment. A caller-selected alternate environment file is ignored. The shared directory and environment must be unlinked, and configuration must be a regular 0600 file owned by root or the executing identity.

The shared deployment lock is acquired before resolving the current release. The resolved directory, 40-character revision, immutable marker, preparation script and executable interpreter are checked and then used consistently for configuration-relative execution, metadata and the final command. A later change to the current pointer cannot retarget the invocation. Required script/marker symlinks are refused; the trusted venv interpreter may retain its existing toolcache symlink.

All supported Sheets credential and workbook aliases, Cloudinary/Gemini/provider aliases, caller Beauty grants, Python import overrides and token/budget-directory context are cleared before the protected source loads. Missing required protected media credentials stop before the Python runner. Its credential-group validation now matches the actual config loader, including protected raw service-account JSON and the legacy workbook-ID alias; an absent or whitespace-only credential/ID group still blocks. The existing protected provider credentials remain available for the existing preparation workflow; this patch does not grant paid execution or initialize an API budget. Caller GitHub model credentials are removed and mock flags are forced false. Publishing, media posting and wrapper download/cut/upload/transcription flags remain false. The unchanged Python runner still owns its bounded prepare-only children and applies the existing activation, per-account, provenance, permission, resource and upload checks.

The existing resource floors are unchanged: at least 4 GiB total memory and 1.5 GiB available memory are required. Low, missing or malformed memory observations defer without loading credentials or invoking the media runner. Deferral is explicitly not proof of fulfilled inventory or migrated scheduler equivalence; the existing fallback responsibility remains. No schedule installation, production setting change, provider request, download, upload, Sheets write or SNS post is part of this source patch.

Offline actual-shell tests use private synthetic runtimes and real advisory locks. Twelve cases cover protected alias precedence, including protected raw service-account JSON with the legacy workbook-ID alias through the actual config loader, caller credential/config denial, disabled mock/post flags, tracing suppression, exact and insufficient/unknown memory floors, lock-before-resolve ordering, pointer races, ownership/symlink/marker checks and unchanged nonzero runner propagation without retries. Existing Python preparation/readiness, resource-budget, host-runtime and deployment-lifecycle contracts are also checked. Combined regression results below remain source evidence; these tests are not live acceptance evidence.
